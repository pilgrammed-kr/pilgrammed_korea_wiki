# V3.1.0 검색과 공략 연결

Goal: 기존 자료의 한국어 공략과 독립 HTML 문서를 홈페이지 및 관련 문서에서 발견하도록 연결합니다.
Architecture: GitHub Pages 정적 호스팅 유지. index.html sourceData를 단일 원본으로 쓰는 표준 Python 생성기. 기록 저장 키·기존 아이템 URL·전체 원본 데이터 유지.

- [x] 보스·퀘스트·지역·NPC·테크닉 정적 문서와 분야별 목차 생성. 기존 아이템 경로에서 획득처/제작/드롭 역참조 연결.
- [x] 한국어 공략 모음에 초반 진행, 정크 피트 선행, Wayfinder, Elite Guard 등 기존 자료로 설명 가능한 안내 배치. 자료 날짜 및 원문 근거 표기; 미확인 경로 생성 금지.
- [x] 홈 화면 및 JS 실행 전 본문에서 문서로 실제 a href 링크 제공. 제목/설명/OG/canonical 일관화. 버전은 검색 제목에 제외.
- [x] sitemap 생성과 CI 업로드 대상 확대. 새 생성기는 Python 표준 라이브러리만 사용.
- [x] 모든 상대 링크, canonical/sitemap 일치, JSON 원본 동일, 저장 키 동일, HTML/JS 검사. 375px 모바일/데스크톱 화면 확인.
- [x] 업데이트 ZIP과 데이터 보존형 Termux 설치 안내 제공. 원격 배포 완료로 표현하지 않음.

검토할 조건: 중복 slug / 알 수 없는 재료 / 그룹 드롭 확률 / 삭제 퀘스트 / 재실행 시 중복 홈 삽입. 정보 부족은 기존 상태대로 표시. 새 검증 날짜를 임의로 부여하지 않음.

추가 승인 범위: 모든 도감 항목으로 확대. 원본 1,279개 전부의 URL 대응을 검사합니다. 추가 지역 모음과 목차·공략을 합쳐 1,364페이지입니다.
